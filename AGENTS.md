# NW Monthly Theme Guidance

- This repository is for NW Monthly only. Do not introduce code, content, branding, or configuration from other sites.
- The theme owns visual and layout work. Keep plugin logic separate unless a theme change requires it.
- Inspect live rendering before making material design changes. Production WordPress is authoritative.
- Preserve responsive behavior, accessibility, navigation, and WordPress hooks.
- Editing this repository is not approval to deploy.
- Make the smallest coherent change.
- Stop on unexpected Git state or any mismatch between production and Git.
